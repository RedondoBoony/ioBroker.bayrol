# ioBroker.bayrol

ioBroker Adapter für Bayrol Pool-Steuerung.

## Einstellungen

| Einstellung | Beschreibung |
|-------------|--------------|
| Benutzername | Bayrol-Benutzername |
| Passwort | Bayrol-Passwort |

## Installation über GitHub

In ioBroker unter **Adapter → Eigene Adapter (von URL)** folgende URL eingeben:

```
https://github.com/RedondoBoony/ioBroker.bayrol
```
